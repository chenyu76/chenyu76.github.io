# 多角星的生成

我们都知道，正五角形只有一种画法（除去平凡的正五边形情形），但当点数增大时，画法就有很多了。我感觉当点数增加时，绘制的形状应该会很好看，于是就写了这个网页画着玩。

结论：确实好看。

这是一个N角形绘制工具， 在框中输入`n₁:m₁, n₂:m₂, ...`格式的数据来绘制图形， 其中`nₛ`是边数，`mₛ`是连接间隔

<p><strong>示例：</strong></p>
<ul>
<li><code>5:2</code> → 五角星（5个顶点，间隔2个点连接）</li>
<li><code>8:3</code> → 八角星（8个顶点，间隔3个点连接）</li>
<li><code>6:2</code> → 六芒星（6个顶点，间隔2个点连接）</li>
<li><code>10:2,5:2</code> → 由两个五角形组成的十角星</li>
<li><code>35:5,7:2</code> → 由5个7角形组成的35角星</li>
</ul>
<p>
<code>mₛ</code>可以替换为<code>[mₛ₁, mₛ₂, ...]</code>
使用不同间隔轮流填充
</p>
<p><strong>示例：</strong></p>
<ul>
<li>
  <code>16:[4,2]</code> → 16角星,但是轮流使用八边形和四边形填充
</li>
</ul>
<p>
在连接间隔后面加上小数点可以使形状不调用接下来的间隔
</p>
<p><strong>示例：</strong></p>
<ul>
<li>
  <code>10:[2,2.],5:2</code> → 由一个五边形和一个五角形组成的10角星
</li>
<li>
  <code>60:[12,12.],5:2</code> → 由五边形和五角形组成的60角星
</li>
</ul>
