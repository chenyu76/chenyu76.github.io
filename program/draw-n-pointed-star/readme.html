多角星的生成

我们都知道，正五角星只有一种画法（除去平凡的正五边形情形），但当点数增大时，画法就有很多了。我感觉当点数增加时，绘制的形状应该会很好看，于是就写了这个网页画着玩。

结论：确实好看。

在下面的输入框中输入n1:m1,n2:m2,…n_1:m_1, n_2:m_2, \dotsn1​:m1​,n2​:m2​,…格式的数据来绘制图形， 其中nin_ini​是边数，mim_imi​是连接间隔，例如输入5:25:25:2表示在一个圆上逆时针均匀排布5个顶点中，每个顶点连接其后第2个顶点(mod5)\pmod 5(mod5)。max⁡ini\max_i n_imaxi​ni​决定绘制的是几角星，剩余的nin_ini​控制子图形的连接间隔。

示例：

  • 5:2 → 五角星（5个顶点，间隔2−1=12-1=12−1=1个点连接）
  • 8:3 → 八角星（8个顶点，间隔3−1=23-1=23−1=2个点连接）
  • 6:2 → 六芒星（6个顶点，间隔2−1=12-1=12−1=1个点连接）
  • 10:2,5:2 → 由两个五角形组成的十角星
  • 35:5,7:2 → 由5个7角形组成的35角星

mim_imi​可以替换为[mi,1,mi,2,… ][m_{i,1},m_{i,2}, \dots][mi,1​,mi,2​,…]使用不同间隔轮流填充

示例：

  • 16:[4,2] → 16角星，但是轮流使用八边形和四边形填充

在连接间隔后面加上小数点可以使形状不调用接下来的间隔

示例：

  • 10:[2,2.],5:2 → 由一个五边形和一个五角形组成的10角星
  • 60:[12,12.],5:2 → 由五边形和五角形组成的60角星

题外话

从群的角度你可以很容易地理解这个程序在做什么，正nnn边形的对称性构成nnn阶循环群 G=Z/nZG=\mathbb{Z}/n\mathbb{Z}G=Z/nZ:

  • 对顶点编号：V={0,1,2,⋯ ,n−1}V = \{0,1,2,\cdots,n-1\}V={0,1,2,⋯,n−1} 对应群元素
  • 配备的运算：模nnn加法 a⊕b=(a+b)mod  na \oplus b = (a + b) \mod na⊕b=(a+b)modn

连接间隔mmm是群生成元，连接操作定义为群作用：i→i+mmod  ni \rightarrow i + m \mod ni→i+mmodn

  • 当 n,mn,mn,m互素时构成单一轨道（orbit），并且也完全生成了整个循环群。
    • 例如五角星 5:25:25:2：
      • 生成元 m=2m=2m=2
      • 连接序列：0→2→4→1→3→00 \rightarrow 2 \rightarrow 4 \rightarrow 1 \rightarrow 3 \rightarrow 00→2→4→1→3→0
  • 当m∣nm \mid nm∣n时，群作用分解为mmm个轨道，每个轨道是大小为n/mn/mn/m的循环子群H≅mZ/nZH \cong m\mathbb{Z}/n\mathbb{Z}H≅mZ/nZ。因此我们可以对这些轨道做递归操作，最后生成复杂图像。例如10角星 10:210:210:2：
    • 轨道1：{0,2,4,6,8}→\{0,2,4,6,8\} \to{0,2,4,6,8}→ 五边形
    • 轨道2：{1,3,5,7,9}→\{1,3,5,7,9\} \to{1,3,5,7,9}→ 五边形
      • 五边形可以再通过5:25:25:2生成五角星

不过如果使用不同间隔[mi,1,mi,2,… ][m_{i,1},m_{i,2}, \dots][mi,1​,mi,2​,…]轮流填充就没有什么理论保证了，所以当你使用这个语法时，有时候会能看到有些顶点被重复使用，有些顶点却没被使用。
