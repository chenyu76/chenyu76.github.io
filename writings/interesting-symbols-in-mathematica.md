## 符号与列表：万物皆表达式的秘密

### 原子与骨架

在Mathematica的宇宙中，一切存在皆为**表达式**。无论是数字`3`、符号`x`、还是复杂算式`Sin[x + 1]`，最终都呈现为同一种数学本质——由**头部(Head)**与**元素(Part)**组成的树状结构。输入`FullForm[a - b]`你将看到震撼的真相：

```mathematica
Plus[a, Times[-1, b]]
```

这里的`Plus`与`Times`即为表达式的头部，而`a`、`Times[-1, b]`则为`Plus`的元素，`-1`和`b`则是`Times`的元素。

这揭示了`a - b`的本质是`a + (-1*b)`，其头部仍然是`Plus`。通过`Head`函数可验证这个发现：

```mathematica
Head[a - b]  (* 输出 Plus *)
```

### 窥视本质的三棱镜

掌握以下工具即可解析任何表达式的DNA：

- `FullForm`：显示完全展开的原始形态
- `TreeForm`：绘制树状结构图
- `Head`：提取表达式的头部

尝试用`TreeForm[# /. x_ :> HoldForm[x]] &`冻结计算过程，你将看到`x + y*z`的真实骨架：

```
   Plus
  /   \
x     Times
      /   \
     y     z
```

### 符号的变装舞会

许多常用符号其实只是 Mathematica 为我们准备的语法糖衣，例如：

| 符号    | 全称         | 备注                     |
| ------- | ------------ | ------------------------ |
| `{...}` | `List`       | 列表                     |
| `=`     | `Set`        | 定义时立即求值右侧       |
| `:=`    | `SetDelayed` | 定义时保留右侧未求量形式 |
| `->`    | `Rule`       | 创建即时生效的替换规则   |
| `/.`    | `ReplaceAll` | 按规则替换               |
| `#`     | `Slot`       | 匿名函数的占位符         |


### 列表：万物的容器

列表`{}`不仅是数据的载体，更是构建世界的积木。输入`FullForm[f[a, b]]`与`FullForm@{a, b}`，你会看到惊人的相似性：

```
f[a, b]
List[a, b]
```

这说明**所有函数调用本质上都是列表的变体**。`Map[f, {a, b}]`与`f /@ {a, b}`的等价性正源于此——列表结构天然适配函数式操作。

## 纯函数：`#` 与 `&`

`#`和`&`是函数式编程的黄金搭档，两者配合便相当于纯函数`Function`。

#### 用途：

- **#**：参数占位符。
- **&**：纯函数终结。

#### 语法示例：

```mathematica
#^2 &[5]                (* 输出25，平方操作 *)
#1 + #2 &[3, 5]         (* 输出8，加法操作 *)
StringJoin[#2, #1] &["A", "B"]  (* 输出"BA"，参数顺序调换 *)
```

#### 黑话指南：

- 单参数时，可以只用 `#` （当然你也可以写`#1`）
- 多参数时，请务必用 `#1`、`#2` 明确编号（否则Mathematica不可能知道你在干什么）
- 想一次引用所有参数？请召唤 `##`（比如

```
In:  ## &[1,2,3]
Out:
```

### 第二章：集合操作的“三幻神”——/@、@@、@@@

这三个符号是操作列表的“三叉戟”，专治各种不服。

#### 1. **/@ （Map）—— 雨露均沾型**

**用途**：让函数关爱列表的每一个元素  
**语法**：`f /@ {a,b,c}` 等价于 `{f[a], f[b], f[c]}`  
**经典翻车现场**：

```mathematica
Sin /@ {1, 2, 3}    (* 正确：{Sin[1], Sin[2], Sin[3]} *)
Sin @ {1, 2, 3}      (* 错误：试图计算Sin[{1,2,3}] *)
```

#### 2. **@@ （Apply）—— 釜底抽薪型**

**用途**：把列表“炸开”作为函数参数  
**语法**：`f @@ {a,b,c}` 等价于 `f[a, b, c]`  
**灵魂拷问**：

```mathematica
Plus @@ {1, 2, 3}   (* 输出6，相当于1+2+3 *)
Join @@ {{1,2}, {3}} (* 输出{1,2,3}，合并列表 *)
```

#### 3. **@@@ （MapApply）—— 层层扒皮型**

**用途**：针对嵌套列表的精准打击  
**语法**：`f @@@ {{a,b}, {c,d}}` 等价于 `{f[a,b], f[c,d]}`  
**高级玩法**：

```mathematica
StringJoin @@@ {{"A","B"}, {"C","D"}}  (* 输出{"AB","CD"} *)
```

---

### 第三章：操作符界的“千面人”—— /. 与 //

这两个符号是代码界的变形金刚，专攻“写代码一时爽，一直写一直爽”的场景。

#### 1. **/. （ReplaceAll）—— 乾坤大挪移**

**用途**：规则替换的闪现技能  
**语法**：`expr /. rule`（把表达式里的元素按规则替换）  
**骚操作示范**：

```mathematica
x + y /. {x -> 2, y -> 3}       (* 输出5 *)
{a, a, b} /. a -> "喵"          (* 输出{"喵","喵",b} *)
```

#### 2. **// （Postfix）—— 倒装句大师**

**用途**：把代码写成“宾语前置”的文言文风格  
**语法**：`expr // f` 等价于 `f[expr]`  
**套娃艺术**：

```mathematica
Range[10] // Total // Sqrt     (* 等价于Sqrt[Total[Range[10]] *)
```

---

### 第四章：符号界的“冷门狠活”

#### 1. **~ （Infix）—— 中缀强迫症患者**

**用途**：把函数写成操作符形式  
**语法**：`a ~f~ b` 等价于 `f[a, b]`  
**使用场景**：

```mathematica
1 ~Plus~ 2             (* 输出3 *)
"Hello" ~StringJoin~ "World"  (* 输出"HelloWorld" *)
```

#### 2. **@_ 与 /_ （Composition）—— 函数拼接怪**

**用途**：把函数像乐高一样拼接  
**语法**：`f @* g` 等价于 `f[g[...]]`（从右到左组合）  
**组合技演示**：

```mathematica
Reverse @* Sort /@ {{3,1,2}, {6,4,5}}  (* 先排序再反转 → {{3,2,1}, {6,5,4} *)
```

### 第五章：函数式编程的“三大纪律”

1. **万物皆表达式**  
   Mathematica的世界里，连数字都是表达式（不信试试 `FullForm[1+2]`）

2. **数据不可变**  
   所有操作都产生新数据，原数据永远神圣不可侵犯：

   ```mathematica
   list = {1, 2, 3};
   newList = Append[list, 4];  (* list还是{1,2,3} *)
   ```

3. **函数是第一公民**  
   函数可以当参数传递、当返回值、甚至被动态生成：
   ```mathematica
   Nest[#^2 &, 2, 3]  (* 2→4→16→256 *)
   ```

### 第六章：防秃头调试指南

#### 1. **优先级血泪史**

符号组合的优先级堪比奥数题，请善用括号：

```mathematica
# & @@ # &        (* 错误！ *)
(# &) @@ (# &)    (* 正确 *)
```

#### 2. **纯函数参数迷惑行为**

多参数时务必明确编号，否则你会看到Mathematica的迷之微笑：

```mathematica
# + #2 &[1, 2]   (* 正确 → 3 *)
# + # &[1, 2]     (* 输出2，它把两个参数都当成# *)
```

#### 3. **结构操作鬼打墙**

分清“操作元素”和“操作结构”：

```mathematica
Sin /@ {1, 2, 3}   (* 正确：逐个应用 *)
Sin @@ {1, 2, 3}    (* 错误：Sin需要1个参数，给了3个 *)
```

### 终极挑战：符号交响诗

**题目**：用一行代码找出1000以内同时满足以下条件的数：

1. 是质数
2. 各位数字之和也是质数
3. 倒过来读还是质数（如13和31）

**答案**：

```mathematica
Select[Prime@Range@168,
  PrimeQ[Total[IntegerDigits[#]] && PrimeQ[FromDigits[Reverse@IntegerDigits[#]]] &]
```
