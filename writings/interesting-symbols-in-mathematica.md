### **函数式编程的数学视角**
想象你正在用数学中的“函数”来构建一个世界。这里的函数不是计算机中的指令，而是数学意义上的映射关系，例如：

- 定义函数 \( f: A \rightarrow B \)，它将集合 \( A \) 中的每个元素映射到集合 \( B \) 中的唯一元素。
- **核心原则**：所有计算都通过这样的函数组合来完成，而非通过“修改状态”或“执行步骤”。

---

### 纯函数
数学函数的特点是**确定性**——相同的输入必定得到相同的输出。例如：
- \( f(x) = x + 1 \)：输入 \( 2 \) 必然输出 \( 3 \)，没有例外。
- **关键**：函数不依赖外部环境（如全局变量），也不改变外部环境（如修改某个变量的值）。它像一个自洽的“黑箱”，仅通过输入和输出来定义。

---

### 数据不可变
在数学中，数值或集合一旦定义，便不可更改。例如：
- 给定集合 \( S = \{1, 2, 3\} \)，若想得到每个元素加 1 后的集合，数学中不会“修改” \( S \)，而是定义新集合 \( S' = \{x + 1 \mid x \in S\} = \{2, 3, 4\} \)。
- **哲学**：函数式编程中，所有数据如同数学对象——操作生成新数据，而非覆盖旧数据。

---

### 高阶函数：函数的函数

函数作为其他函数的输入或输出。例如：
- **函数的复合**：若 \( f(x) = x^2 \)，\( g(x) = x + 1 \)，则复合函数 \( f \circ g(x) = (x + 1)^2 \)。
- **泛函**：如微分算子 \( D \)，它将一个函数映射到其导数（\( D(f) = f' \)）。
- **意义**：高阶函数允许将行为抽象为参数，灵活组合逻辑。

---

### 递归：数学归纳法的实现

常用递归定义对象，例如：
- **阶乘**：\( n! = n \times (n-1)! \)，基例 \( 0! = 1 \)。
- **斐波那契数列**：\( F(n) = F(n-1) + F(n-2) \)，基例 \( F(0)=0, F(1)=1 \)。
- **思想**：通过将问题分解为更小的同类问题来求解，而非依赖循环步骤。


### 函数式编程的优势
- **可预测性**：纯函数如数学公式，输入确定则输出唯一，减少隐藏错误。
- **可组合性**：函数像乐高积木，通过组合简单函数构建复杂逻辑（如 \( h(x) = f(g(x)) \)）。
- **并行安全**：无副作用使得函数可独立运行，无需担心竞争条件。
- **数学友好**：逻辑可直接对应数学理论，适合算法证明与推导。

### 对比：命令式 vs 函数式
- **命令式**：像“做菜步骤”——“先切菜，再热锅，然后炒...”，强调如何逐步修改状态。
- **函数式**：像“数学公式”——定义输入到输出的映射规则，强调“做什么”而非“怎么做”。

### 总结
**函数式编程的本质，是将计算视为数学函数的求值过程**。它通过纯函数、不可变数据和高阶抽象，构建出一个稳定、可推理的编程范式。就像用数学公式推导问题一样，每一步都清晰无歧义——这正是它被许多复杂系统青睐的原因。

## 符号与列表：万物皆表达式的秘密

### 原子与骨架

在Mathematica的宇宙中，一切存在皆为**表达式**。无论是数字`3`、符号`x`、还是复杂算式`Sin[x + 1]`，最终都呈现为同一种数学本质——由**头部(Head)**与**元素(Part)**组成的树状结构。运行`FullForm[a - b]`你将看到震撼的真相：

```mathematica
Plus[a, Times[-1, b]]
```

这里的`Plus`与`Times`即为表达式的头部，而`a`、`Times[-1, b]`则为`Plus`的元素，`-1`和`b`则是`Times`的元素。

这揭示了`a - b`的本质是`a + (-1*b)`，其头部仍然是`Plus`。你可以通过`Head`函数验证这个发现：

```Mathematica
Head[a - b]  
(* Out: Plus *)
```

### 窥视本质的三棱镜

掌握以下工具即可解析任何表达式的内在本质：

- `FullForm`：显示完全展开的原始形态
- `TreeForm`：绘制树状结构图
- `Head`：提取表达式的头部

尝试用`TreeForm[x + y * z]`绘制树状图，你将看到`x + y*z`的真实骨架：

```
   Plus
  /   \
x     Times
      /   \
     y     z
```

就连函数定义本质上也是如此：（这里使用了`Hold`防止内部被自动求值）
```Mathematica
FullForm[Hold[f[a_]:=a^2]]
(* Out: Hold[SetDelayed[f[Pattern[a,Blank[]]],Power[a,2]]] *)
```

## 符号的缩写

许多常用符号其实只是 Mathematica 为我们准备的语法糖衣，例如：

| 符号    | 全称         | 备注                     |
| ------- | ------------ | ------------------------ |
| `{...}` | `List`       | 列表                     |
| `=`     | `Set`        | 定义时立即求值右侧       |
| `:=`    | `SetDelayed` | 定义时保留右侧未求量形式 |
| `->`    | `Rule`       | 创建即时生效的替换规则   |
| `/.`    | `ReplaceAll` | 按规则替换               |
| `#`     | `Slot`       | 匿名函数的占位符         |

你可能暂时无法理解上表中的备注的含义，别急，后文中你将会得到解释。


## 列表：万物的容器

列表`{}`不仅是数据的载体，更是构建世界的积木。输入`FullForm[f[a, b]]`与`FullForm[{a, b}]`，你会看到惊人的相似性：

```
f[a, b]
List[a, b]
```

这说明**所有函数调用本质上都是列表的变体**。`Map[f, {a, b}]`与`f /@ {a, b}`的等价性正源于此——列表结构天然适配函数式操作。

## 但等等，什么是函数式操作？

我们先介绍一个概念：

### 纯函数

#### 1：相同输入 → 永远相同输出
```mathematica
(* 纯函数示例：加法 *)
add[a_, b_] := a + b;

(* 调用 *)
add[2, 3]  (* 输出始终是 5 *)
```
- 像数学中的函数 $f(x, y) = x + y$ ，输入 $(2, 3)$ 永远返回 $5$ 。

#### 2：无副作用

除了返回一个值外，什么都不会发生。例如，`Print`就是一个典型的不纯函数，它产生了副作用：将参数输出到屏幕上。

### 函数式编程（Functional Programming）的核心理念

用函数（特别是纯函数）和表达式来操作数据。

### 和传统编程的区别

假设你要将列表 `{1, 2, 3}` 中的每个元素加 1：
- **传统方式（命令式循环）**：
  ```mathematica
  numbers = {1, 2, 3};
  newNumbers = {0, 0, 0};
  For[i = 1, i <= Length[numbers], i++, 
    newNumbers[[i]] = numbers[[i]] + 1
  ]
  ```
- **函数式编程**：将集合 $\{1,2,3\}$ 直接通过函数 $f(x) := x+1$ 映射到 $\{2,3,4\}$.
  
  ```mathematica
  numbers = {1, 2, 3};
  newNumbers = Map[Function[x, x+1], numbers] 
  (* 或更简洁的写法：# + 1 & /@ numbers *)
  ```

---

### 函数式编程的重要概念

#### 纯函数（Pure Function）

用 `Function` 或 `#&` 语法定义无副作用的函数：

```mathematica
(* 纯函数：输入相同，输出一定相同 *)
add = Function[{a, b}, a + b];
add[2, 3] (* 输出 5 *)

(* 更简洁的纯函数写法 *)
add = #1 + #2 &;
add[2, 3] (* 输出 5 *)
```

#### 数据不可变（Immutable Data）
Mathematica 中的列表操作默认生成新数据：
```mathematica
(* 传统方式：修改原列表（不推荐） *)
AppendTo[arr, 4]; 

(* 函数式：生成新列表 *)
newArr = Append[arr, 4]; (* 原列表 arr 不变 *)
```

#### 高阶函数（Higher-Order Function）
函数可以作为参数或返回值：
```mathematica
(* 使用内置高阶函数 Map/Select *)
Map[# * 2 &, {1, 2, 3}] (* 输出 {2, 4, 6} *)
Select[{1, 2, 3}, # % 2 == 0 &] (* 输出 {2} *)

(* 函数作为返回值 *)
createAdder[a_] := Function[b, a + b];
add5 = createAdder[5];
add5[3] (* 输出 8 *)
```

#### 用递归代替循环

递归在 Mathematica 中很自然：

```mathematica
(* 计算阶乘 *)
factorial[n_] := If[n == 0, 1, n * factorial[n - 1]];
factorial[5]
(* 输出 120 *)
```

---

### 函数式编程的优势
- **简洁性**：用内置高阶函数（如 `Map`、`Select`、`Fold`）替代循环。
- **数学友好**：直接表达数学逻辑（如符号计算、模式匹配）。
- **可组合性**：通过 `@`、`/*`、`//` 等操作符链式调用函数。
  ```mathematica
  (* 链式调用示例 *)
  {1, 2, 3, 4} // Map[# + 1 &] // Select[EvenQ] (* 输出 {2, 4} *)
  ```

---

### 实际代码对比
过滤列表中的偶数：
- **传统方式**：
  ```mathematica
  arr = {1, 2, 3, 4};
  evens = {};
  Do[If[EvenQ[arr[[i]]], AppendTo[evens, arr[[i]]], {i, 1, Length[arr]}];
  ```
- **函数式**：
  ```mathematica
  evens = Select[{1, 2, 3, 4}, EvenQ] (* 或更简洁的写法：Select[EvenQ]@{1,2,3,4} *)
  ```
  **区别**：函数式代码更简洁且无副作用。

---

### Mathematica 特有的函数式技巧
#### ① **符号计算与规则替换**
  ```mathematica
  (* 用规则替换实现函数式操作 *)
  {1, 2, 3} /. x_ :> x + 1 (* 输出 {2, 3, 4} *)
  ```

#### ② **模式匹配**
  ```mathematica
  (* 用模式匹配定义递归函数 *)
  clearAll[factorial];
  factorial[0] = 1;
  factorial[n_] := n * factorial[n - 1];
  ```

#### ③ **柯里化（Currying）**
  ```mathematica
  (* 柯里化加法函数 *)
  addCurry[a_] := Function[b, a + b];
  addCurry[5][3] (* 输出 8 *)
  ```

---

### 7. **适合什么场景？**
- **符号数学计算**：微积分、代数化简。
- **数据转换与筛选**：列表、关联数组的操作。
- **算法原型设计**：快速验证数学逻辑。

### 总结
**在 Mathematica 中，函数式编程是通过纯函数、高阶函数（如 `Map`/`Select`）和不可变数据实现的自然风格**。它的核心优势是：
- 代码简洁如数学公式
- 内置大量函数式工具（如 `Nest`、`Fold`、`Compose`）
- 天然支持符号计算与模式匹配

尝试多用 `#&` 纯函数、避免修改变量（如不用 `AppendTo`），你会感受到 Mathematica 函数式编程的强大！

## 第二章：匿名函数与映射魔法

### #&：函数式编程的魔法卷轴
在Wolfram语言中，最神秘的符号组合`#&`实则是**匿名函数**的咒语。`#`作为占位符，`&`则是触发函数化的魔杖：

```mathematica
#^2 + 1 &  (* 等价于 Function[x, x^2 + 1] *)
```

当配合`/@`（Map的简写）使用时，会产生惊人的链式反应：
```mathematica
# <> "!" & /@ {"Hello", "World"}  (* 输出 {"Hello!", "World!"} *)
```
这实际上是通过`Slot`（#）构建的即时函数，在内存中完成了一次优雅的字符串变换舞蹈。

（配图：标注#符号流动路径的映射过程示意图）

### /@：空间折叠术
这个看似外星符号的操作符，本质是`Map[f, expr]`的语法糖。但它的魔力在于**自动穿透容器**：

```mathematica
f /@ {{a, b}, {c, d}}  (* 输出 {f[{a, b}], f[{c, d}]} *)
f @@@ {{a, b}, {c, d}} (* 输出 {f[a, b], f[c, d]} *)
```

通过`TreeForm`观察`Map[f, g[h[x], y]]`，你会看到函数`f`如同幽灵般穿透不同层级的容器：
```
     g
    / \
 f[h[x]] f[y]
```

### @@：头冠更替仪式
当`@@`（Apply的简写）出现时，意味着一场头颅替换的仪式正在发生：

```mathematica
Plus @@ {1, 2, 3}  (* 等价于 Apply[Plus, {1,2,3}] *)
```
此时列表的`List`头部被斩首，替换为`Plus`头颅，触发`1+2+3`的运算。而`@@@`则是穿透容器的深度斩首术：
```mathematica
f @@@ {{a, b}, {c, d}}  (* 输出 {f[a,b], f[c,d]} *)
```

### //：时空管道
这个被称为右管道的操作符，能将代码改写成瀑布般流畅的形态：
```mathematica
Range[10] // Select[#, PrimeQ] & // Total
```
等价于
```mathematica
Total[Select[Range[10], PrimeQ]]
```
通过`//`构建的流水线，让数据如同穿过魔能反应堆般层层转化。

（代码对比示意图：传统嵌套写法 vs 管道式写法）

### 函数组合玄学
当`@*`（Composition）与`/*`（RightComposition）相遇时，函数式编程展现出拓扑学般的精妙：

```mathematica
Reverse @* Sort /@ {{3,1,2}, {9,5,7}}  (* 先排序再反转 *)
FileNames /* Select[StringContainsQ["report"]] /* Length (* 文件筛选流水线 *)
```

这里`@*`如同函数焊接器，将多个操作熔铸成原子般不可分割的新函数。而`Sum`本质上正是：
```mathematica
Sum[f[k], {k, 1, 10}]  ⟺  Add @* Table[f[k], {k, 1, 10}]
```
