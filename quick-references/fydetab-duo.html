Android

ArchLinux

Arch Linux如wiki上写的开箱即用，我通过Rufus安装到tf中，这样在拔出tf卡后还可以回到Fyde OS，某种不算很方便的双系统。

安装后

换源

清华大学开源软件镜像站 Arch Linux ARM 软件仓库

输入法

gnome使用iBus

sudo pacman -S ibus-rime

重启后去设置里配置键盘即可。

中文字体

刚安装好时缺字体，从这里抄一份字体清单。

sudo pacman -S adobe-source-han-serif-cn-fonts wqy-zenhei # 安装几个开源中文字体。一般装上文泉驿就能解决大多 wine 应用中文方块的问题
sudo pacman -S noto-fonts noto-fonts-cjk noto-fonts-emoji noto-fonts-extra # 安装谷歌开源字体及表情

GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
