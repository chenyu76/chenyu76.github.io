/网站生成/

网站编译流程

通过Github action, 每次push上去时会通过npm调用webGenerate/main.ts，将目录下的.md文件都转成.html,然后遍历文件夹，将这些html加入到网站目录中

Github仓库

配置在webConfig.js中的仓库会被下载到对应位置。可以访问

主页推荐

  • 配置在webConfig.js中的推荐会被显示在主页上
  • 同时可以同步一些别的仓库到网站上，如果没有index，readme会被重命名为index

特殊的markdown语法

网站处理markdown文件时具有以下附加特性：

  • 第一行如果以# 开头，这个标题会被作为文章大标题和标签页标题。
  • 最后一行如果是日期，会被作为脚注使用小号的灰色字体附在文末。同时文末的分隔符（如果有）会被删除。
  • 如果一个代码块里包含unicode线段（┌ ┐ └ ┘ ─ │），这个代码块会被显示为让线能连起来的紧凑格式、使用白色背景、不显示复制按钮
  • 支持公式，但是似乎由于我的配置原因行间公式前面需要有两个或以上的\n；并且$$后面必须立即跟随\n，$开头的行内公式前面必须有一个空格。

手动使用

生成：

npm start

清理：

npm run clean
